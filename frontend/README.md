# GuitarRiff — Frontend

Squelette Vite + React + TypeScript (Étape 2 — fondations). Aucune
fonctionnalité de transcription audio n'est encore branchée à l'API.

## Commandes

```bash
npm install
npm run dev      # serveur de développement
npm run build    # build de production (dist/)
npm run test     # tests (Vitest + Testing Library)
npm run lint     # lint (oxlint)
```

Voir `../docs/ARCHITECTURE.md` pour la place du frontend dans le projet.
